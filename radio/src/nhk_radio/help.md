# NHK ラジオ 聞き逃し ヘルプ

NHK ラジオ聞き逃しダウンローダーの公式使い方説明書です。番組の検索、お気に入り管理、エピソード取得、一括ダウンロード、再生、表示設定、CLI 操作までをまとめて確認できます。

## はじめに

- **この画面でできること**: 配信中の番組を探し、エピソード一覧を取得して複数話を一括ダウンロードできます。保存済みファイルの再生、保存先フォルダの開く操作、表示テーマや文字サイズの調整もこの GUI 内で完結します。
- **画面の4エリア構成**:
  - **ヘッダー（最上部）**: アプリ名と `ヘルプ` / `表示設定` ボタンがあります。
  - **左ペイン（番組一覧）**: ジャンル絞り込み・キーワード検索・番組リスト（`↻ 更新` ボタン付き）があります。
  - **右上ペイン（番組概要とエピソード一覧）**: 選択番組の情報・`☆ お気に入り` / `保存先を開く` / `一覧を取得`、エピソード検索・`保存済みのみ`・`未保存を選択`・エピソード表とダウンロードボタンがあります。
  - **右下ペイン（ダウンロード進捗）**: 進行中・完了済みジョブの進捗バー、`すべて中止`、`完了分をクリア` が表示されます（待機中はコンパクト表示になります）。
  - **ステータスバー（最下部）**: 現在の操作状況、ショートカットヒント、セルクリック時の選択セルコピー欄が表示されます。

## 基本操作の流れ（クイックスタート）

1. **番組を探す**: 左側の一覧から番組を選ぶか、上部の検索欄やジャンル絞り込みで目的の番組を見つけます。
2. **エピソード一覧を取得する**: 番組をダブルクリック（または選択して `Enter` / `F` キー / `一覧を取得` ボタン）して配信回を読み込みます。キャッシュがある場合は選択と同時に自動表示されます。
3. **保存したい回を選ぶ**: 右側のエピソード一覧で必要な回をクリックします。複数選択（`Cmd/Ctrl + クリック` / `Shift + クリック` / `U` キーで未保存を一括選択）も可能です。
4. **ダウンロードを開始する**: `Enter` / ダブルクリック / `D` キー / `選択エピソードをダウンロード` を押すと、右下のダウンロード進捗エリアが広がり保存が始まります。
5. **保存した音声を聴く**: 保存が完了すると DL 列に `☑` が表示されます。`☑` をクリックして既定プレイヤーで再生するか、ヒーロー部の `保存先を開く` からフォルダを開きます。

## 番組一覧の使い方

- **番組検索**: 番組名、corner 名、ジャンル名を横断検索できます。検索語は自動正規化（全角/半角・大小文字を区別しない）され、入力履歴は自動保存されて次回以降の候補として再利用できます。`クリア` ボタンまたは検索欄での `Esc` キーで検索語を消去できます。
- **お気に入り (★)**: ヒーロー部の `☆ お気に入り` ボタン（または `B` キー）でよく聴く番組を登録・解除できます。登録された番組は一覧上で番組名の先頭に `★` が付き、ジャンル絞り込みの `★ お気に入り` を選ぶと登録番組だけを表示できます。設定ファイルに自動保存されます。
- **ジャンル絞り込み**: `すべて` / `★ お気に入り` 以外を選ぶと、指定ジャンルの番組だけを表示します。検索欄との併用も可能です。
- **番組一覧の更新**: 番組一覧見出し横の `↻ 更新` ボタンで、番組一覧キャッシュを破棄して NHK から最新の一覧を再取得します。
- **列見出しソート**: `番組名` や `ジャンル` などの列見出しをクリックすると昇順・降順を切り替えられます。もう一度クリックすると逆順になります。
- **一覧取得**: 番組を選択して `Enter` / ダブルクリック / `F` キー / `一覧を取得` ボタンで最新一覧を取得します。すでに有効なキャッシュがある場合は番組をクリックした時点で即座に表示されます。

## エピソード一覧の使い方

- **検索による絞り込み**: 右側上部の検索欄で、エピソードのタイトル・表示タイトル・放送日・放送時刻・長さを対象にリアルタイムで絞り込めます。`クリア` または `Esc` で解除できます。
- **保存済みのみ**: 保存済みエピソードだけを表示したいときは `保存済みのみ` チェックを ON にします。ローカルにダウンロード済みの回だけを確認・再生したいときに便利です。
- **未保存を選択**: `未保存を選択` ボタン（または `U` キー）を押すと、現在表示されているエピソードのうち未保存の回だけをまとめて選択状態にします。新着回をまとめて保存したいときに便利です。
- **保存先を開く**: ヒーロー部の `保存先を開く` ボタンで、選択中番組の保存先フォルダを OS のファイラー（Finder / エクスプローラー等）で直接開けます。
- **複数選択操作**: `Cmd/Ctrl + クリック` で個別追加・解除、`Shift + クリック` で範囲選択、`Space` キーでも選択を操作できます。現在の選択件数はツールバー上部に表示されます。
- **保存済み状態の確認**: 保存済みの回は DL 列に `☑` が付きます（番組概要欄にも保存済み件数が表示されます）。

## ダウンロードと進捗

- **ダウンロード開始**: エピソードを選択して `D` キー、または `選択エピソードをダウンロード` ボタンで即座にダウンロードを開始します。エピソード行のダブルクリックや `Enter` キーでも開始できます。
- **上書き確認**: すでに保存済みのエピソードが選択に含まれている場合は確認ダイアログが表示され、再保存するかスキップするかを選べます。
- **進捗エリアの自動展開とコンパクト表示**: 待機中（ジョブ 0 件のとき）は進捗エリアがコンパクトな高さに自動で縮み、エピソード一覧を広く使えます。ダウンロードを開始すると自動で展開され、進捗バー・パーセント・残り時間 (ETA) がリアルタイム更新されます。
- **ジョブの中断・一括中止・クリア**: 各ダウンロード行のボタンから個別中断でき、進行中のジョブがある間はヘッダーの `すべて中止` ボタンからすべてを一括中断できます。終了したジョブは `完了分をクリア` で一覧から消去できます。
- **再ダウンロード**: 完了済みまたは失敗済みのジョブを再実行するときは、ジョブ行が自動的に再生成されて進捗追跡が途切れません。

## ダウンロード後の再生方法

- **GUI から直接再生する**: エピソード一覧の DL 列にある `☑` マークを左クリックすると、OS 既定の音楽プレイヤーで音声ファイルが開きます。
- **右クリックコンテキストメニュー**: エピソード一覧の行を右クリックすると、以下の操作メニューを利用できます。
  - `既定プレイヤーで再生`: 保存済み音声を既定のアプリで再生します。
  - `保存先フォルダを開く`: 番組の保存先ディレクトリを開きます。
  - `ファイルパスをコピー`: 保存済み音声ファイルのフルパスをクリップボードへコピーします。
  - `ファイル名をコピー`: 保存済み音声ファイル名のみをコピーします。
  - `保存済みファイルを削除`: ディスク上の音声ファイルと保存履歴を削除します（確認ダイアログあり）。
  - `再度ダウンロード`: 保存済みエピソードを取り直します。
  - `番組ページを開く`: NHK 公式の番組ページを Web ブラウザで開きます。
- **フォルダから再生する**: `保存先を開く` や右クリックメニューで開いたフォルダ内の `.mp3` / `.m4a` ファイルをダブルクリックし、任意のプレイヤー（Music.app, VLC, QuickTime Player など）で再生してください。
- **セル値のコピー**: 表内の任意のセルをクリックすると画面下部に選択セル欄が表示され、`Ctrl/Cmd + C` または `セル値をコピー` ボタンで値をクリップボードにコピーできます。欄は右端の `✕` で閉じられます。

## 表示設定

- **表示設定ダイアログ**: ヘッダーの `表示設定` ボタンでモーダルダイアログが開きます。テーマや文字サイズの変更はその場でメイン画面に即時反映されます。
- **ライト / ダークテーマ**: 周囲の環境や好みに合わせてライトテーマ・ダークテーマを切り替えられます。
- **文字サイズ調整**: 9pt〜18pt の範囲でスライダー・プリセットボタン・増減ボタンから文字サイズを調整できます。
- **保存と未保存確認**: `保存して戻る` で設定ファイルへ永続化され、次回起動時にも引き継がれます。未保存のまま `戻る` や `Esc` / 閉じる操作を行うと、保存・破棄・キャンセルの確認ダイアログが表示されます。
- **キャッシュ削除・リセット**: ダイアログ上部の `キャッシュを全削除` で番組一覧・エピソード一覧のキャッシュのみを安全に削除できます（お気に入り・テーマ設定・保存済み音声は保持されます）。`規定値にリセット` でライトテーマ・11pt に戻せます。

## 説明書の検索と目次移動

- **説明書を開く**: ヘッダーの `ヘルプ` ボタン、またはブラウザ画面で `F1` / `?` キーを押すといつでも開けます。
- **目次から章へ移動する**: ダイアログ左側の目次一覧から見たいセクションをクリックすると、右側の本文がその見出し位置まで即座にスクロールします。
- **キーワード検索**: ダイアログ上部の検索欄（または `Ctrl/Cmd + F`）にキーワードを入力すると、説明書内の該当箇所がすべてリアルタイムでハイライトされ、一致件数と現在位置（例: `1 / 5 件`）が表示されます。大小文字や全角・半角の違いを区別せずに検索できます。
- **一致箇所を順にたどる**: 検索欄で `Enter` または `▼ 次へ` ボタンで次の一致箇所へ、`Shift + Enter` または `▲ 前へ` ボタンで前の一致箇所へ移動できます。末尾から先頭（先頭から末尾）へループ移動します。
- **検索のクリアと終了**: `クリア` ボタンで検索語を消去できます。`Esc` キーは検索語が入力されている場合は検索語をクリアし、検索語が空の場合は説明書ダイアログを閉じます。

## コマンドライン (CLI) の使い方

ターミナルから `python3 nhk_radio_dl.py` または `nhk-radio` コマンドで起動できます。GUI を使えない環境では対話式 CLI モードへ自動でフォールバックします。

```bash
# GUI モードで起動
python3 nhk_radio_dl.py

# 番組 URL を直接指定して全エピソードをダウンロード
python3 nhk_radio_dl.py "https://www.nhk.or.jp/radio/ondemand/detail.html?p=XXXX_01"

# 直近 N 件だけ保存し、保存先ディレクトリも指定
python3 nhk_radio_dl.py "https://www.nhk.or.jp/radio/ondemand/detail.html?p=XXXX_01" -n 5 -o ~/Downloads/nhk

# 特定ジャンルだけ読み込んで GUI 起動
python3 nhk_radio_dl.py -g language

# キャッシュのみを削除して終了（設定・お気に入り・保存済み音声は保持）
python3 nhk_radio_dl.py --clear-cache
```

- `url`: 番組 URL（省略時は GUI モードで起動します）
- `--output-dir`, `-o`: 保存先ディレクトリ（デフォルト: `./downloads`）
- `--max-items`, `-n`: 最大ダウンロード件数（1 以上の整数）
- `--keep-video`: 音声変換せず元のメディアファイルを保持します
- `--clear-cache`: 番組一覧・エピソード一覧のキャッシュを削除して終了します
- `--genre`, `-g`: 指定ジャンルだけで絞り込みます
- `--verbose`, `-v`: デバッグ用の詳細ログを出力します

## 保存先と設定ファイルの場所

- **ダウンロード音声の保存先**: デフォルトでは `./downloads/<site_id>_<corner_id>/YYYYMMDD_<番組名>_<回タイトル>.mp3` として保存されます。同じディレクトリ内の `.downloaded.json` に取得済み履歴が記録され、二重保存を防ぎます。
- **キャッシュの場所**: 番組一覧キャッシュは `.cache/programs/`、エピソード一覧キャッシュは `.cache/episodes/` に保存されます。パッケージとしてインストールした場合は OS 標準のユーザーキャッシュフォルダが使われます。環境変数 `NHK_RADIO_CACHE_DIR` で変更可能です。
- **設定ファイルの場所**: テーマ・文字サイズ・検索履歴・お気に入り番組・ヘルプ確認バージョンは `.config/ui_settings.json`（パッケージ利用時は OS 標準のユーザー設定フォルダ）に保存されます。環境変数 `NHK_RADIO_CONFIG_DIR` で変更可能です。

## トラブルシューティング

- **一覧取得に失敗する**: 一時的なネットワーク障害や番組側の配信終了・変更が原因の場合があります。取得失敗時に期限切れのローカルキャッシュが存在する場合は、自動的にその内容を表示して閲覧できるようにしています。
- **ダウンロードができない (`yt-dlp` エラー)**: 外部コマンド `yt-dlp`（および音声変換用の `ffmpeg`）がインストールされて PATH が通っているか確認してください。
- **ダウンロード済みなのに見つからない / 再生できない**: DL 列の `☑` や `保存先を開く` で実ファイルが開けない場合は、保存フォルダの移動やファイル削除が行われていないか確認してください。ステータスバーに記録パスやエラー原因が表示されます。再度取り直したい場合は、右クリックメニューの `再度ダウンロード` を利用できます。
- **動作が重い**: 検索欄やジャンル絞り込みで表示件数を絞る、`完了分をクリア` で過去のジョブ行を整理する、または `表示設定` ダイアログ内の `キャッシュを全削除` を実行することで動作が軽快になります。
