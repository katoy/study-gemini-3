# NHK ラジオ 聞き逃し ヘルプ

番組の検索、エピソード取得、ダウンロード、保存済み確認、表示設定までを一通り迷わず使えるようにしたガイドです。

## はじめに

- **この画面でできること**: 番組を探し、エピソード一覧を取得し、複数選択して一括ダウンロードできます。保存済みファイルの確認や表示設定の調整もこの GUI で完結します。
- **基本の流れ**: 1. 左側で番組を探す 2. 一覧を取得する 3. 右側で対象回を絞る 4. ダウンロードを開始する 5. 下部で進捗を確認する

## 番組一覧の使い方

- **番組検索**: 番組名、corner 名、ジャンル名を横断検索できます。履歴は自動保存され、次回起動時にも候補として使えます。
- **ジャンル絞り込み**: `すべて` 以外を選ぶと、一覧をそのジャンルだけに絞れます。検索との併用も可能です。
- **一覧取得**: 番組を選択して `Enter` / ダブルクリック / `F` キー / `一覧を取得` ボタンで最新一覧を取得します。キャッシュがあれば即表示します。

## エピソード一覧の使い方

- **絞り込み**: 右側上部の検索欄でタイトル・放送日・放送時刻・長さを対象に絞り込めます。
- **保存済みのみ**: 保存済みだけ見たいときは `保存済みのみ` を ON にします。再取得済みの回だけ確認したいときに便利です。
- **複数選択**: `Cmd/Ctrl + クリック`、`Shift + クリック`、`Space` を使って複数選択できます。選択件数は上部に表示されます。
- **保存済み確認**: DL 列の `済` を押すと保存先ポップアップが開き、パスコピーやフォルダオープンができます。

## ダウンロードと進捗

- **ダウンロード開始**: `Enter` / ダブルクリック / `D` キー / `選択エピソードをダウンロード` ボタンで開始します。
- **ジョブ管理**: 下部のジョブ一覧に各エピソードの進捗、残り時間、状態が表示されます。実行中は中断、完了後は削除ができます。
- **再ダウンロード**: 完了済み・失敗済みジョブを再実行するときは、行を自動的に作り直して追跡が途切れないようにしています。

## ダウンロード後の再生方法

- **GUI から確認する**: エピソード一覧の DL 列にある `済` を押すと保存済みファイルのポップアップが開きます。ここで保存先パスを確認したり、フォルダを開いたりできます。
- **フォルダから再生する**: 保存済みファイルポップアップの `フォルダオープン` で保存フォルダを開き、Finder / エクスプローラー上で mp3 や m4a ファイルを通常の音楽プレーヤーで再生してください。
- **パスを使って開く**: `PATHのコピー` でフルパスをコピーし、VLC、Music.app、QuickTime Player など任意のプレーヤーに渡して再生できます。

## 表示設定

- **表示設定画面**: ヘッダーの `表示設定` からテーマと文字サイズを調整できます。設定はその場で即時反映されます。
- **保存と破棄**: 保存すると次回起動時にも引き継がれます。未保存のまま戻ると変更は破棄されます。
- **リセット**: 規定値に戻すと、ライトテーマと標準文字サイズに戻ります。

## ショートカット

- `Ctrl/Cmd + F`: 番組検索欄へフォーカス
- `Ctrl/Cmd + L`: エピソード検索欄へフォーカス
- `F1` / `?`: このヘルプを開く
- `F`: 選択番組のエピソード一覧を取得
- `D`: 選択エピソードをダウンロード
- `Esc`: ヘルプや保存済みポップアップを閉じる / 設定画面から戻る / 検索欄をクリア
- `Ctrl/Cmd + C`: 選択セルの値や保存先パスをコピー

## トラブルシューティング

- **一覧取得に失敗する**: 一時的なネットワーク障害や番組側の配信状態が原因のことがあります。取得失敗時は期限切れキャッシュがあれば自動表示します。
- **ダウンロード済みなのに見つからない**: 保存先ポップアップで実ファイルが見つからない場合は、保存フォルダの移動や削除がないか確認してください。
- **動作が重い**: 検索条件を絞る、完了済みジョブを削除する、キャッシュを整理することで一覧操作が軽くなることがあります。
