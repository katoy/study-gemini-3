## 1. セキュリティ指摘と対応内容

### S5. 【Medium】キャッシュファイルパスの未サニタイズによるパストラバーサル
- **問題**: `cache._program_cache_path` と `cache._episode_cache_path` が `genre` / `site_id` / `corner_id` を `_safe_name` に通さず連結しており、`../` を含む値でキャッシュディレクトリ外へ脱出するおそれがあった。
- **対応**: `_program_cache_path` と `_episode_cache_path` のファイル名要素を `_safe_name` で無害化した。

### S6. 【Medium】エピソード URL およびキャッシュ復元時の URL スキーム・ホスト未検証
- **問題**:
  1. `_parse_episode_info` で `ep_id` が空のとき、未検証の `webpage_url` / `url` がそのまま `Episode.url` に入っていた。また `ep_id` の文字種を制限していなかった。
  2. `resolve_program_from_url` でキャッシュ上の番組情報を返す際、キャッシュ内の `candidate.url` をそのまま返していた。
- **対応**: `is_valid_nhk_url(url, allow_stream=...)` を追加し、`http`/`https` と許可ホスト（`www.nhk.or.jp`、ストリーム許可時は `vod-stream.nhk.jp`）を検証した。`ep_id` は `[\da-zA-Z_-]+` に制限し、`resolve_program_from_url` ではキャッシュ一致時も正規化済み `program.url` を適用するようにした。

### S7. 【Medium】フォルダオープン・クリーンアップのシンボリックリンク境界未確認および `.app` 起動リスク
- **問題**:
  1. `open_downloaded_folder` は `is_dir()` のみを確認していたため、macOS の `.app` バンドル（実体はディレクトリ）やそれを指すリンクを `open` で起動するおそれがあった。また `_open_downloaded_episode_folder` は `output_dir` 境界を検証していなかった。
  2. `cleanup_partial_episode_files` と `cleanup_residual_backup_files` が外部を指すシンボリックリンクディレクトリを走査・操作し得た。
- **対応**: `open_downloaded_folder` で `.app` サフィックス（`realpath` 含む）を拒否し、`_open_downloaded_episode_folder`・`cleanup_partial_episode_files` で `is_within_output_dir` を検証、`cleanup_residual_backup_files` で `not os.path.islink(p)` によりシンボリックリンクディレクトリを除外した。

### S8. 【Low】`mark_episode_downloaded` の境界確認欠落と `runner.py` のメディア拡張子漏れ
- **問題**: `mark_episode_downloaded` が `output_dir` 外のパスでも記録可能だった。また `run_yt_dlp_subprocess` の出力パス検出が `.mp3` / `.m4a` / `.mp4` のみに限定され `.aac` / `.wav` が漏れていた。
- **対応**: `mark_episode_downloaded` に `is_within_output_dir(path, output_dir)` を追加し、`runner.py` の拡張子判定を `MEDIA_EXTENSIONS` に統一した。

## 2. 機能バグ・保守性の対応内容

- **B1（削除時の即時反映漏れ）**: `_delete_episode_file` で `displayed_saved_keys.discard(...)`、ツリー行の `☑` 消去、ボタン状態・概要統計の更新を同期で行い、削除前の `was_saved_only` 状態に基づいて即座に再絞り込みするようにした。あわせて `_apply_saved_keys` でも `_refresh_saved_only_button_state()` 呼び出し前の `was_saved_only` を保持し、最後の保存済み 1 件削除時も確実に再描画するようにした。
- **B2（放送日時ソート不整合）**: `episodes.py` の `"date"` ソートを JST 表示日付（`_sortable_day_value`）と `broadcast_time` の組に統一し、`programs.py` の `"date"` ソートでも `_sortable_day_value` を使うようにした。
- **B3（切り詰めファイル名の照合漏れ）**: `filesystem.py` に `_truncate_utf8` を追加し、`_episode_output_patterns` と `_episode_output_matches` が `_episode_title_max_bytes` による切り詰め後タイトルも照合・掃除できるようにした。これにより `download_url_direct` 等でマニフェスト未記録のまま保存された長大タイトル回でも保存済み判定と `.part` 掃除が一致する（注: `download_url_direct` 自体でプレイリスト各回の `.downloaded.json` を個別に記録する仕組みは追加していない）。
- **B4（旧保存先でのフォルダオープン）**: `_open_downloaded_episode_folder` が `find_episode_downloaded_path` で見つかった実ファイルの親ディレクトリを優先して開くようにした。
- **B5（設定ダイアログ上確認の `parent`）**: `_settings_dialog_parent()` を追加し、設定ダイアログ表示中の `_reset_ui_settings` / `_confirm_leave_settings` の確認ダイアログが設定ダイアログを親にするよう修正した。
- **M1（ドキュメント整合）**: `README.md` の設定パス（`.config/ui_settings.json` / `NHK_RADIO_CONFIG_DIR`）、テスト件数（603 件）、カバレッジ表、および `cli.py --help` の保存先例を更新した。
- **M2（未使用コードとデモスクリプト）**: `browser.py` の `saved_episode_buttons` / `saved_episode_popup`、`protocols.py` の `saved_button` / `_is_episode_downloaded` を削除し、`scripts/generate_demo.py` の `download_finished_count` 参照を `browser.active_download_rows` 参照へ修正した。
