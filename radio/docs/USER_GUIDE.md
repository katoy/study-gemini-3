# NHK ラジオ 聞き逃しダウンローダー 使い方説明書

本ドキュメントは、NHK ラジオ聞き逃しダウンローダーの GUI 操作・CLI 操作・保存先管理・トラブルシューティングをまとめた完全ガイドです。
同じ内容のガイドはアプリ内の **「ヘルプ」ボタン**（または `F1` / `?` キー）からも参照・検索できます。

## 1. はじめに（画面構成）

GUI 画面は次の 4 エリアで構成されています。

| エリア | 主な機能 |
|:-------|:---------|
| **ヘッダー（最上部）** | アプリタイトル、`ヘルプ` ボタン（説明書を開く）、`表示設定` ボタン |
| **左ペイン（番組一覧）** | ジャンル絞り込み（`すべて` / `★ お気に入り` / 各ジャンル）、キーワード検索（履歴付き）、`↻ 更新` ボタン、番組リスト |
| **右上ペイン（概要とエピソード一覧）** | 番組概要（`☆ お気に入り` / `保存先を開く` / `一覧を取得`）、エピソード絞り込み（検索 / `保存済みのみ` / `未保存を選択`）、エピソード一覧、ダウンロード開始ボタン |
| **右下ペイン（ダウンロード進捗）** | 待機中はコンパクト表示。DL 開始時に展開し、各ジョブの進捗・個別中断、`すべて中止`、`完了分をクリア` を表示 |
| **ステータスバー（最下部）** | 操作結果メッセージ、ショートカットヒント、セルクリック時の選択セル値コピー欄 |

## 2. 基本操作の流れ（クイックスタート）

1. **番組を探す**: 左側の一覧から番組を選ぶか、上部の検索欄やジャンル絞り込みで目的の番組を探します。
2. **エピソード一覧を取得する**: 番組をダブルクリック（または選択して `Enter` / `F` キー / `一覧を取得` ボタン）します。有効なキャッシュがある番組はクリックと同時に自動表示されます。
3. **保存したい回を選ぶ**: 右側のエピソード一覧から保存したい回をクリックします。`Cmd/Ctrl + クリック`、`Shift + クリック`、または `未保存を選択`（`U` キー）で複数回をまとめて選択できます。
4. **ダウンロードを開始する**: `D` キーまたは `選択エピソードをダウンロード` ボタン（単一選択なら行のダブルクリック / `Enter` も可）で保存を開始します。
5. **保存した音声を聴く**: 完了すると DL 列に `☑` マークが付きます。`☑` をクリックすると OS 既定のプレイヤーで再生でき、ヒーロー部の `保存先を開く` から保存フォルダを直接開けます。

---

## 3. 番組一覧の使い方

- **横断検索**: 番組名・コーナー名・ジャンル名（英語/日本語）を対象に検索します。全角・半角や大文字・小文字は区別されません。入力した検索語は最大 30 件まで履歴として自動保存され、次回以降も候補から呼び出せます。検索欄右側の `クリア` ボタンまたは `Esc` キーで検索語を消去できます。
- **お気に入り登録 (`★`)**:
  - ヒーロー部の `☆ お気に入り` ボタン（または `B` キー）で選択中番組をお気に入りに登録/解除できます。
  - お気に入り登録した番組は一覧上で番組名の先頭に `★ ` が付き、ジャンル絞り込みの `★ お気に入り` を選ぶと登録済み番組だけを一覧表示できます。
  - 登録内容は設定ファイル (`ui_settings.json`) に即座に自動保存されます。
- **番組一覧の更新 (`↻ 更新`)**: 見出し横の `↻ 更新` ボタンを押すと、番組一覧キャッシュを破棄して NHK から最新一覧を再取得します。
- **列見出しソート**: 列見出しをクリックすると、No.・番組名・ジャンル等の並び順を昇順/降順で切り替えられます。

---

## 4. エピソード一覧の使い方

- **メタデータ絞り込み**: 右上ペインの検索欄では、**タイトル・表示タイトル・放送日・放送時刻・長さ** を対象にリアルタイムで絞り込みできます。
- **保存済みのみ表示**: `保存済みのみ` チェックボックスを ON にすると、ローカルに保存済みのエピソードだけを表示します。
- **未保存を一括選択**: `未保存を選択` ボタン（または `U` キー）で、現在表示中のエピソードのうち未保存の回だけをすべて選択状態にします。
- **保存先を開く**: ヒーロー部の `保存先を開く` ボタンで、選択中番組の保存フォルダ（`downloads/<site_id>_<corner_id>/`）を Finder / エクスプローラー等で開きます。
- **一覧の再取得**: 番組を選択後、`F` キーまたは `一覧を再取得` ボタンで最新の一覧を取り直せます。

## 5. ダウンロードと進捗管理

- **開始方法**: `D` キー、`選択エピソードをダウンロード` ボタン、またはエピソード行のダブルクリック / `Enter` キー（確認ダイアログあり）でダウンロードを開始します。
- **上書き確認**: 選択したエピソードに保存済みの回が含まれている場合は確認ダイアログが表示され、再保存するかスキップするかを選べます。
- **待機中コンパクト表示と自動展開**: ダウンロードジョブがない間は右下の進捗エリアがコンパクトな高さに折りたたまれ、エピソード一覧を広く表示できます。ジョブを追加すると自動で展開します。
- **中止と整理**:
  - 各行の中断ボタンで 1 件ずつキャンセルできます。
  - 実行中ジョブがある間は右下の見出しに `すべて中止` ボタンが表示され、全ジョブを一括キャンセルできます。
  - 終了済み（完了・エラー・中止）の行は `完了分をクリア` でまとめて消去できます。

---

## 6. ダウンロード後の再生とファイル操作

- **ワンクリック再生**: エピソード一覧の `DL` 列にある `☑` を左クリックすると、OS 既定のアプリで音声ファイルを開きます。
- **右クリックメニュー**: エピソード一覧の行を右クリックすると、次の操作メニューを表示できます。
  1. `既定プレイヤーで再生`
  2. `保存先フォルダを開く`
  3. `ファイルパスをコピー`
  4. `ファイル名をコピー`
  5. `保存済みファイルを削除`（確認ダイアログ後にディスクと履歴から削除）
  6. `再度ダウンロード`
  7. `番組ページを開く`（NHK 公式ページをブラウザで開く）
- **セル値のコピー**: 一覧の任意のセルをクリックすると画面最下部に「選択セル欄」が表示され、`Ctrl/Cmd + C` または `セル値をコピー` ボタンでそのセルの文字をコピーできます。不要時は右端の `✕` で閉じられます。

## 7. 表示設定とキャッシュ管理

ヘッダー右上の `表示設定` ボタンからモーダルダイアログを開けます。

- **テーマ切替**: ライトテーマ / ダークテーマを即時プレビュー付きで切り替えられます。
- **文字サイズ**: `9pt` 〜 `18pt` の範囲でスライダー・プリセットボタン・`−`/`＋` ボタンで調整できます。
- **保存と未保存確認**: `保存して戻る` で設定を永続化します。未保存のままダイアログを閉じようとすると「保存 / 破棄 / キャンセル」を確認します。
- **キャッシュを全削除**: ダイアログ上部の `キャッシュを全削除` で番組一覧・エピソード一覧キャッシュだけを削除できます（お気に入り・テーマ・文字サイズ・保存済み音声は維持されます）。
- **規定値にリセット**: ライトテーマ・11pt に戻します。

## 8. アプリ内説明書（ヘルプ）の参照と検索

ヘッダーの `ヘルプ` ボタン、または `F1` / `?` キーで「使い方説明書 / ヘルプ」ダイアログを開けます。

- **左ペイン（目次）**: 各章・節が一覧表示されます。クリックすると右側の本文がその見出しの先頭へ即座にスクロールします。
- **上部検索バー（リアルタイム検索 & ハイライト）**:
  - キーワードを入力すると本文内のすべての一致箇所がハイライトされ、現在選択中の箇所が強調表示されます（大小文字・全角/半角を区別しません）。
  - 一致件数（例: `1 / 5 件`）が横にリアルタイム表示されます。
  - `Enter` または `▼ 次へ` ボタンで次の一致箇所へ、`Shift + Enter` または `▲ 前へ` ボタンで前の一致箇所へ移動できます（先頭/末尾でループします）。
  - ダイアログ表示中に `Ctrl/Cmd + F` を押すと説明書内の検索欄へ直接フォーカスします。
  - `Esc` キーは検索語が入力されていれば検索語をクリアし、空の場合は説明書ダイアログを閉じます。

## 9. コマンドライン (CLI) の使い方

```bash
# GUI モードで起動
python3 nhk_radio_dl.py

# 番組 URL を直接指定してダウンロード
python3 nhk_radio_dl.py "https://www.nhk.or.jp/radio/ondemand/detail.html?p=XXXX_01"

# 直近 5 件だけ保存し、保存先ディレクトリを変更
python3 nhk_radio_dl.py "https://www.nhk.or.jp/radio/ondemand/detail.html?p=XXXX_01" -n 5 -o ~/Downloads/nhk

# 特定ジャンル（例: language）だけで絞り込んで GUI 起動
python3 nhk_radio_dl.py -g language

# 一覧キャッシュのみを削除して終了
python3 nhk_radio_dl.py --clear-cache
```

| オプション | 説明 |
|:-----------|:-----|
| `url` | 番組 URL（省略時は GUI モード起動） |
| `-o`, `--output-dir` | 保存先ディレクトリ（デフォルト: `./downloads`） |
| `-n`, `--max-items` | 最大ダウンロード件数（1 以上の整数） |
| `--keep-video` | 音声変換せず元のファイルを保持 |
| `--clear-cache` | 番組・エピソード一覧キャッシュを削除して終了 |
| `-g`, `--genre` | 指定ジャンルのみで絞り込み |
| `-v`, `--verbose` | 詳細ログ（DEBUG）を出力 |

## 10. 保存先と設定ファイル・環境変数

- **音声ファイル保存先**: `downloads/<site_id>_<corner_id>/YYYYMMDD_<番組名>_<回タイトル>.mp3`
  - 同じディレクトリにダウンロード済み追跡用マニフェスト `.downloaded.json` が作成されます。
- **キャッシュ保存先**: `.cache/programs/` と `.cache/episodes/`
  - パッケージとしてインストールした場合は OS 標準のキャッシュディレクトリを使用します。
  - 環境変数 `NHK_RADIO_CACHE_DIR` で上書きできます。
- **UI 設定ファイル**: `.config/ui_settings.json`
  - テーマ、文字サイズ、番組検索履歴、お気に入り番組、ヘルプ確認済みバージョンを保存します。
  - パッケージとしてインストールした場合は OS 標準の設定ディレクトリを使用します。
  - 環境変数 `NHK_RADIO_CONFIG_DIR` で上書きできます。

## 11. キーボードショートカット一覧

| キー | 動作 |
|:-----|:-----|
| `Ctrl/Cmd + F` | 番組検索欄（説明書表示中は説明書検索欄）へフォーカス |
| `Ctrl/Cmd + L` | エピソード検索欄へフォーカス |
| `F` | 選択番組のエピソード一覧を取得 |
| `D` | 選択エピソードをダウンロード |
| `B` | 選択番組のお気に入り登録 / 解除 |
| `U` | 表示中の未保存エピソードをすべて選択 |
| `F1` / `?` | 使い方説明書 / ヘルプを開く |
| `Esc` | 説明書検索クリアまたは説明書を閉じる / 表示設定を閉じる / 検索欄をクリア |
| `Ctrl/Cmd + C` | 選択セルの値をクリップボードにコピー |

## 12. ジャンル一覧

番組検索欄や `-g` オプションでは以下のジャンルキー／日本語名が利用できます。

- `new_series`: 新番組
- `news`: ニュース
- `sports`: スポーツ
- `information`: 情報/ワイドショー
- `drama`: ドラマ
- `music`: 音楽

- `welfare`: 福祉
- `kids`: キッズ
- `language`: 語学
- `local`: 地域放送局

## 13. トラブルシューティング

- **`yt-dlp` が見つからない / ダウンロードに失敗する**: `yt-dlp --version` および `ffmpeg -version` が端末で実行できるか確認してください。
- **一覧取得に失敗する**: 一時的なネットワーク障害時は、期限切れであってもローカルキャッシュが存在すれば自動表示されます。復帰後に番組一覧の `↻ 更新` や `一覧を再取得` を実行してください。
- **保存済みなのにファイルが見つからない / 再生できない**: 保存ディレクトリが移動・削除されていないか確認してください。右クリックメニューの `再度ダウンロード` で取り直すこともできます。
- **GUI が起動しない**: `python3 -m tkinter` で Tkinter が利用可能か確認してください。利用できない環境では `python3 nhk_radio_dl.py` は自動で CLI 対話モードに切り替わります。
