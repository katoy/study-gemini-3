# PDF 分割スキル

このスキルは、フォルダ内のすべての PDF ファイルをスキャンし、20MB 以上のファイルを同じページ数になるように分割します。

## 使用方法

```
フォルダパスを指定して、フォルダ内のすべての PDF を 20MB 以下に分割してください。
```

## 処理フロー

1. **フォルダスキャン** — 指定されたフォルダ内のすべての PDF を検出
2. **OCR処理の実行** — 各 PDF に対して `ocrmypdf` を用いた OCR 処理を適用し、テキスト検索可能な一時ファイルを作成
3. **ファイルサイズチェック** — 各 OCR 済み PDF のサイズを確認
4. **出力フォルダ作成** — `split_output` フォルダを作成
5. **処理実行**
   - **20MB 以下**：そのままコピー（OCR済みPDFを出力）
   - **20MB 以上**：同じページ数になるように分割
6. **結果保存** — 分割/コピーされたファイルを出力フォルダに保存し、一時的なOCR中間ファイルを削除

## ファイル命名規則

分割されたファイルの命名例：
- 元のファイル：`document.pdf`（25MB）
- 分割後：
  - `document_part1.pdf`
  - `document_part2.pdf`

## 実装ステップ

1. Python スクリプト `scripts/split_pdf.py` を作成
2. PyPDF (pypdf) を使用してページ数を取得
3. 分割数を計算：`分割数 = ⌈ファイルサイズ / 20MB⌉`
4. 各パートが同じページ数になるように分割
5. 出力フォルダに保存

## 注意事項

- スクリプトは同期処理（ファイルサイズが大きい場合は時間がかかる可能性あり）
- 元のフォルダは変更しない
- 出力フォルダが既に存在する場合は上書き
