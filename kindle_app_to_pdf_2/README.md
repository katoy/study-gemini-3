# Kindle to PDF Converter

Kindle Cloud Reader または Kindle デスクトップアプリの画面を自動的に送りながらスクリーンショットを撮影し、一つの PDF ファイルに結合するツールです。

## 参考：

- https://www.youtube.com/watch?v=4mNWR2GiqK0
  MacでPythonを使ってKindleをPDF化する方法

この動画から gemini を使ってソースコードを抽出させてます。


## 機能

- 指定したページ数の自動スクリーンショット撮影
- ページめくり方向（右送り・左送り）の指定
- 撮影した画像の高品質 JPEG 保存（`KindleScreenshots/` ディレクトリ）
- 撮影完了後の自動 PDF 変換

## 必要条件

- Python 3.6 以上
- Kindle アプリ（またはブラウザでの閲覧環境）

## セットアップ

1. このリポジトリをクローンまたはダウンロードします。
2. 必要なライブラリをインストールします。

```bash
pip install -r requirements.txt
```

## 使い方

1. Kindle アプリを開き、撮影を開始したいページを表示します。
2. ターミナルでプログラムを実行します。

```bash
# デフォルト（右送り、200ページ）
python main.py

# ページ数と方向を指定する場合
python main.py --pages 50 --direction left
```

3. 実行後、5秒間の待機時間があります。その間に Kindle アプリをアクティブ（最前面）にしてください。
4. 自動的に撮影が始まります。終了するまでマウスやキーボードを操作しないでください。

## オプション引数

- `--pages`: 撮影するページ数（デフォルト: 200）
- `--direction`: ページめくりの方向。`right`（右送り）または `left`（左送り）を選択（デフォルト: `right`）

## 注意事項

- **著作権について**: 本ツールの使用は、私的使用の範囲に留めてください。作成した PDF を再配布・公開することは法律で禁止されています。
- **実行中の操作**: 実行中は `pyautogui` がキーボード出力をシミュレートするため、他の作業は行わないでください。
- **中断**: 途中で止めたい場合は、ターミナルで `Ctrl + C` を押してください。それまでに撮影したページで PDF が作成されます。
- **Windows での実行**: Kindle アプリが管理者権限で動いている場合、このスクリプトも管理者権限で実行する必要があります。
