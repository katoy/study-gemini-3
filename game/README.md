# 潮風の諸島（しおかぜのしょとう）

1つのHTMLファイル（`index.html`）だけで遊べる、完全オリジナルのターン制群島開拓ストラテジーゲームです。  
夜明け前の霧に包まれた7×7の六角形（ヘックス）群島マップを舞台に、プレイヤー（青の船団）とCPU（赤の船団）が島々を開拓し、勢力を競います。

## 遊び方・起動方法

Web 上で今すぐプレイできます：  
👉 **[潮風の諸島をプレイする (GitHub Pages)](https://katoy.github.io/study-gemini-3/)**

また、外部ライブラリや画像・音声ファイルは一切使用していないため、ローカルの `index.html` をブラウザで開くだけでもそのままプレイできます（PC・スマートフォンの両方に対応）。

```bash
open index.html
```

## ゲームルール

### 盤面と初期資源
- **マップ構成**: 7×7（全49マス：陸地40マス・海9マス）の六角形マスで構成される群島マップ（ゲーム開始ごとにランダム生成・全陸地マスの連結性を保証）
  - 陸地40マスの内訳：港 2 ／ 森 12 ／ 漁場 11 ／ 岩山 10 ／ 平原 5
- **スタート地点と初期資源**: プレイヤー（青の船団）は左上の「港」、CPU（赤の船団）は右下の「港」から開始し、両陣営とも初期資源として **木材 4・食料 2・石 2** を保有した状態でスタートします。
- **マスの種類と資源獲得**: ターンの最初に、自分が所有しているマスから資源を受け取ります。
  - **森**: 木材 +1
  - **漁場**: 食料 +1
  - **岩山**: 石 +1
  - **平原**: 資源なし
  - **港**: 本拠地（資源なし・攻略不可）
  - **海**: 進入不可

### ターン進行と4つの行動
交互にターンを行い、1ターンに **最大2回** まで行動できます。盤面のマスをクリック（またはタップ）すると、そのマスで実行可能な行動ボタンが表示されます。

| 行動 | 対象マス | 必要資源 | 効果 |
| :--- | :--- | :--- | :--- |
| **開拓** | 自分のマスに隣接する空きマス | 木材 2 | 空きマスを取得して自軍の領土にする（+1点） |
| **攻略** | 自分のマスに隣接する相手マス | 食料 2 ＋ 石 1<br>（砦あり：食料 4 ＋ 石 2） | 相手のマスを奪う（港マスは攻略不可。砦がある場合は陥落時に破壊され、市場がある場合はそのまま奪取できる） |
| **砦を建てる** | 自分の所有マス（港・既存建物除く） | 石 2 | 防衛を強化し、相手から攻略されにくくなる（+1点） |
| **市場を建てる** | 自分の資源マス（森・漁場・岩山） | 木材 1 ＋ 石 1 | そのマスから得られる資源が2倍になる（+2点） |

### 得点と勝利条件
- **得点計算**:
  - 所有マス：1点
  - 市場：2点
  - 砦：1点
- **勝利条件**:
  1. **通常勝利**: 全20ターン（両者10回ずつ）終了時に、総得点が多い方の勝利
  2. **即勝利**: ゲーム途中で **陸地マスの60%以上（24 / 40 マス）** を支配した時点で即勝利

## CPU難易度

タイトル画面で3段階の難易度から選択できます。

- **やさしい**: 実行可能な行動の中からランダムに選択します。
- **ふつう**: その行動で増える得点と将来得られる資源価値を計算し、最も評価の高い行動を選択します。
- **つよい**: 「ふつう」の思考に加え、プレイヤーの次ターンの資源と攻略可能範囲を予測し、狙われやすい要所に先回りして砦を建設します。

## 自動テスト・Lint・カバレッジ計測

- **動作要件**: Node.js v20.6 以降（推奨：Node.js v22 以上）
- 外部パッケージ不要で、Node.js 標準のテストランナーとカバレッジ計測機能を用いて `index.html` 内の全ゲームロジック・UI操作・描画・効果音・CPU思考・静的Lint制約（禁止デザイン・ストレージ不使用・構文検証）を実行できます。

```bash
# 構文チェック（Lint）
node --check tests/game.test.js

# 自動テスト＆100%カバレッジ閾値チェック実行
node --test --experimental-test-coverage \
  --test-coverage-include=index.html \
  --test-coverage-lines=100 \
  --test-coverage-branches=100 \
  --test-coverage-functions=100 \
  tests/game.test.js
```
