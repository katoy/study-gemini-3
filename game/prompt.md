# 目的
1つのHTMLファイルだけで遊べる、完全オリジナルのターン制戦略ゲームを作ってください。
# 世界観
- タイトル：潮風の諸島（しおかぜのしょとう）
- 霧に包まれた群島で、プレイヤー（青の船団）とCPU（赤の船団）が島々を開拓し、勢力を競う
# 盤面
- 六角形のマスが並ぶ 7×7 の群島マップ（ゲーム開始ごとにランダム生成）
- マスの種類：森（木材）、漁場（食料）、岩山（石）、平原（資源なし）、海（進入不可）
- プレイヤーは左上、CPUは右下の「港」マスからスタート
# ルール
- 交互にターンを行う。ターンの最初に、自分のマスから資源を受け取る（森→木材1、漁場→食
料1、岩山→石1）
- 1ターンに行動は2回まで。選べる行動は次の4つ
1. 開拓：自分のマスに隣接する空きマスを取得する（木材2）
2. 攻略：自分のマスに隣接する相手のマスを奪う（食料2＋石1。砦のあるマスは食料4＋石2）
3. 砦を建てる：自分のマスに建てる。攻略されにくくなる（石2）
4. 市場を建てる：自分の資源マスに建てる。そのマスの資源が2倍になる（木材1＋石1）
- 港マスは攻略できない
- 得点：マス1点、市場2点、砦1点
- 勝利条件：全20ターン（両者10回ずつ）終了時に得点が多い方の勝ち。途中で陸地マスの60%
以上を支配したら即勝利
# CPU
- 難易度を3段階から選べる
- やさしい：可能な行動からランダムに選ぶ
- ふつう：その行動で得点と資源がどれだけ増えるかを計算し、
一番よい行動を選ぶ
- つよい：「ふつう」に加えて、プレイヤーの次のターンの攻略を読んで砦を建てる
- CPUの行動は1手ずつアニメーションで見せ、何をしたかをログに表示する
# 画面
- タイトル画面（遊び方の説明と難易度選択）、プレイ画面、勝敗画面、リトライ
- プレイ画面：盤面、両者の資源と得点、残りターン数、行動ログ、「ターン終了」ボタン
- マスをクリックすると、そのマスで選べる行動だけをボタンで表示する。資源が足りない行動は
押せないようにする
- マスにマウスを乗せると、種類・所有者・建物・得られる資源を表示する
- 画像ファイルは使わず、すべてCanvasまたはSVGで描画する。効果音はWeb Audio APIで生
成する
- ゲームの状態は変数で保持する（ブラウザの保存機能は使わない）
- PCとスマホの両方で遊べる
# デザイン
- 夜明け前の海をイメージした、深い藍色と潮の青緑を基調に、自軍は青、CPUは赤で塗り分け
る
- 次のものは使わない：クリーム色や生成り色の背景、見出しの一部だけを斜体にする装飾、「
01／02／03」のような番号ラベル、等幅フォントのラベル、角の丸いピル型ボタン
# 品質
- 出力前にコードを見直し、次の点を確認する
- タイトル→20ターン終了→勝敗画面→リトライが最後まで動く
- CPUが行動できない状況でも止まらず、ターンを終了する
- 資源が足りない行動は実行できない
- 60%支配の即勝利が正しく判定される
