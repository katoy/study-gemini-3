# VoiceInput - 完全ローカル LLM 音声入力デスクトップアプリ

![macOS 15.0+](https://img.shields.io/badge/macOS-15.0%2B-blue)
![Swift 6.0](https://img.shields.io/badge/Swift-6.0-orange)
![License MIT](https://img.shields.io/badge/License-MIT-green)

完全ローカル環境で動作する、Apple Silicon Mac 向けの高品質・低遅延音声入力デスクトップアプリケーション（Swift 6 / SwiftUI / AppKit）です。

音声認識（ASR）と小型LLM/ルールベース後処理（Refiner）を組み合わせ、**フィラー除去**、**言い直しの解決**、**句読点付与**、**ユーザー辞書適用**、および**アクティブアプリへの即時自動テキスト挿入**をオフラインで実現します。

## 🌟 主な機能

- **完全ローカル & プライバシー保護 (NFR-3)**
  - 音声データ・認識テキスト・ユーザー辞書は外部サーバーへ一切送信されず、完全にローカル端末内で処理されます。
- **プラグイン型 4層アーキテクチャ (FR-5)**
  - `VADEngine`（音声区間検出）
  - `StreamingASREngine`（リアルタイムプレビュー）
  - `BatchASREngine`（高精度確定転写）
  - `RefinerEngine`（LLM / ルールベース整形）
  - コード本体を変更せずにエンジンを柔軟に拡張・差し替え可能です。
- **LLM 整形 & 後処理 (FR-3)**
  - 「えーと」「あのー」などのフィラー除去 (FR-3.1)
  - 「AAAじゃなくてBBB」といった言い直し・自己修正の自動解決 (FR-3.2)
  - 文脈に応じた句読点・改行付与 (FR-3.3)
  - カナ読みから正式表記へのユーザー辞書変換 (FR-3.4 / FR-6)
- **カーソル位置への自動テキスト挿入 (FR-4.1 / FR-4.2)**
  - グローバルショートカット（`Option + Space`）で音声入力後、任意のアクティブアプリ（Slack, エディタ, ブラウザ等）のカーソル位置へ認識テキストを直ちに自動ペースト。
  - 挿入前のクリップボード内容は自動的に退避・復元されます。
- **メニューバー常駐 & 多機能 HUD (FR-1 / FR-6.1 / FR-4.3 / FR-4.4)**
  - メニューバー常駐アイコンおよびフローティング HUD ウィンドウを提供。
  - **音声入力タブ**: 録音ステータス・リアルタイムプレビューを表示
  - **履歴タブ**: 直近の転写結果（最大保持件数制御・FIFO自動整理および一括クリア機能）を一覧化し、再コピー可能
  - **辞書タブ**: GUI から単語の「読み → 正式表記」ペアを追加・削除

## 🏗️ システム構成図

```text
┌─────────────────────────── macOS固有層 ───────────────────────────┐
│  メニューバーUI / HUD / グローバルホットキー / アクセシビリティ挿入   │
└──────────────────────────────┬────────────────────────────────────┘
                               │
┌────────────────────── パイプラインコア(OS非依存) ─────────────────┐
│                                                                     │
│  AudioCapture → [VADEngine] ─┬→ [StreamingASREngine] → プレビュー   │
│                              └→ 発話確定 → [BatchASREngine]         │
│                                     → OutputValidator                │
│                                     → [RefinerEngine(LLM)]          │
│                                     → 最終テキスト                   │
│                                                                     │
│  ※ [ ] はプロトコル境界 = 差し替え可能なエンジンスロット             │
└─────────────────────────────────────────────────────────────────────┘
```

## 📋 動作要件

- **OS**: macOS 15.0 (Sequoia) 以降
- **対応ハードウェア**: Apple Silicon Mac (M1 / M2 / M3 / M4 / M5)
- **開発環境**: Swift 6.0+ / Xcode 16+

## 🚀 ビルドと実行

### 1. ビルド & テスト

```bash
# デバッグビルド
swift build

# リリースビルド（最適化有効）
swift build -c release

# Swift Testing によるユニットテストの実行
swift test
```

### 2. アプリの起動

```bash
# デバッグ実行
swift run voice_input

# リリースビルドの実行
swift run -c release voice_input
# または生成されたバイナリを直接実行
./.build/release/voice_input
```

### 3. ビルド生成物・キャッシュのクリーンアップ

```bash
# ビルド中間生成物 (.build / .swiftpm) や一時ファイルを削除
./scripts/clean.sh
```

> **注意**: アクティブアプリのカーソル位置への自動テキスト挿入およびマイク録音を利用するには、macOS の「システム設定」→「プライバシーとセキュリティ」から以下を許可してください:
> - **アクセシビリティ**: キー送信およびフォーカスアプリ取得に必要
> - **マイク**: 音声入力に必要
> - **音声認識**: SFSpeechRecognizer の使用に必要
