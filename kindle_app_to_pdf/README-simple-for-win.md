## 1. 事前準備 (Windows のディスプレイ設定と Kindle の用意)

### ディスプレイの拡大縮小設定を「100%」にする (超重要)
Windows のスクリーンショット撮影ライブラリは、ディスプレイの「拡大縮小（スケーリング）」設定が 100% 以外になっていると、ウィンドウの検知ズレやキャプチャ範囲が一部のみになってしまう不具合が発生します。実行前に必ず以下の設定を行ってください。

1. デスクトップの何もないところを右クリックし、**「ディスプレイ設定」** を選択します。
2. 「縮小とレイアウト」（または「拡大縮小とレイアウト」）セクションにある **「拡大縮小」** の項目を確認します。
3. 設定を **「100%」** に変更します。(「125%」や「150%」が推奨値になっている場合でも、一時的に **100%** に設定してください)
4. **マルチディスプレイ (外部モニター) 環境の場合:** Kindle アプリを表示させるモニター側を選択し、そのモニターの拡大縮小設定も必ず **100%** にしてください。(Kindle はメインモニターで表示することを強く推奨します)

### Kindle for PC の準備
1. Amazon 公式サイトまたは Microsoft Store から **「Kindle for PC (Kindle デスクトップアプリ)」** をインストールし、ログインします。
2. PDF に変換したい書籍をあらかじめライブラリからダブルクリックして、ローカルPCにダウンロードしておきます。

## 2. 環境構築 (`uv` のインストールとセットアップ)

本ツールは、Python 環境を高速に管理できるツール `uv` を使用して `.\run.bat` を実行します。

### uv のインストール手順
1. キーボードの `Windows キー` を押し、検索窓に「**PowerShell**」と入力して、Windows PowerShell を起動します。
2. 以下のコマンドをコピーして PowerShell に貼り付け、`Enter` キーを押して実行します。
   ```powershell
   powershell -ExecutionPolicy Bypass -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```
3. インストール完了メッセージが出たら、**開いている PowerShell などのターミナルウィンドウをすべて一旦閉じます**。(パスを有効化するために必須の手順です)
4. **【推奨】** 新しく PowerShell を起動し、本ツールのフォルダに移動して以下のコマンドを実行し、ライブラリの初期セットアップ（同期）を行います。
   ```powershell
   uv sync
   ```
   *(※ これにより、自動的に仮想環境 `.venv` が作成され、依存するすべてのライブラリが自動インストールされます)*

## 3. ツールを実行して PDF を作成する手順

### 手順 1: Kindle アプリで本を開く
1. Kindle for PC アプリを起動します。
2. PDF 化したい本をダブルクリックして開きます。
3. **最初のページ (表紙、またはキャプチャを開始したいページ)** を表示します。
4. **【重要】** Kindle 内の書籍本文が表示されている領域 (ページの中央付近) を、**マウスで一度左クリック** しておきます。これにより、ページめくりのキー入力が Kindle アプリに正しく伝わるようフォーカスがセットされます。

### 手順 2: ターミナルから `run.bat` を実行する
1. 新しく **PowerShell** (または コマンドプロンプト) を起動します。
2. `cd` コマンドで本ツールのフォルダに移動します。
   ```powershell
   cd C:\path\to\kindle_app_to_pdf
   ```
   *(※ `C:\path\to...` の部分は、ツールが配置されている実際のフォルダパスに置き換えてください)*
3. ツール起動コマンドを実行します。
   - **PowerShell の場合:**
     ```powershell
     .\run.bat
     ```
   - **コマンドプロンプトの場合:**
     ```cmd
     run.bat
     ```
   *(※ すでに `uv sync` を実行してセットアップが完了していれば、すぐにツールが起動します。まだ行っていなくても、`run.bat` が自動的に仮想環境をチェックし、`uv run` を通じて必要なライブラリのインストールと実行を行います)*

### 手順 3: キャプチャの開始
1. ターミナルに以下のメッセージが表示されます。
   ```text
   Kindle アプリで処理したい本を開き、最初のページを表示してください。
   準備ができたら Enter キーを押してください。
   （終了する場合は 'q' を入力して Enter）
   ```
2. Kindle アプリが最初のページを開いており、かつ手順1で本文をクリック済みであることを確認し、ターミナルで **Enter** キーを押します。
3. ツールが自動的に Kindle のウィンドウを検知し、最前面に表示してキャプチャを開始します。
4. ターミナルに `キャプチャ中: 1 ページ目...` などのログが表示され、自動的にページがめくられて撮影が繰り返されます。
   * **※ 注意:** キャプチャが完了するまで、**PCのマウスやキーボードの操作は絶対に行わないでください**。画面に他のウィンドウが重なったり、フォーカスが外れると正しく撮影できません。

### 手順 4: キャプチャ自動終了と PDF 生成
1. 最後のページに到達すると、ページめくりを試みても画像が変化しなくなります。
2. ツールは「3回連続で同一の画面が撮影されたこと」を自動検知し、キャプチャを停止します。
3. 撮影された画像から、画質劣化のない高解像度 PDF が自動で生成され、`output` フォルダ内に保存されます。
4. 完了すると、作成された PDF の絶対パスが画面に表示されます。
   * デフォルト設定では、PDF 生成後に一時的に使用した PNG 画像は自動で削除されます。

### 手順 5: 次の書籍の処理またはツールの終了
1. 1冊処理が終わると、ターミナルに以下のプロンプトが表示されます。
   ```text
   次の本を処理しますか？
   ```
2. **別の本も続けて PDF 化したい場合:**
   Kindle で次の本を開いて最初のページを表示し、本文領域をクリックしてから、ターミナルでそのまま `Enter` キーを押します。
3. **終了する場合:**
   ターミナルに `q` を入力して `Enter` キーを押します。

## 4. 便利なオプション機能

`.\run.bat` の後ろにオプションを追加することで、動作をカスタマイズできます。

### ページめくりキーを変更する (`--direction`)
デフォルトでは「右矢印キー(`right`)」でページをめくります。もし動かない場合や、横スクロール・縦スクロール書籍で「スペースキー(`space`)」や「左矢印キー(`left`)」を使いたい場合は指定してください。
- **スペースキーでめくる場合:**
  ```powershell
  .\run.bat --direction space
  ```
- **左矢印キーでめくる場合 (逆スクロール本など):**
  ```powershell
  .\run.bat --direction left
  ```

### ページめくり後の待機秒数を調整する (`--page-delay`)
デフォルトの待機時間は `1.5` 秒です。表示が重い電子書籍、ローディングアニメーションが発生する書籍、ネットワーク接続が必要な書籍の場合は、待機時間を長め（例: `2.5` 秒など）に設定することでキャプチャ漏れを防ぎます。
- **待機時間を 2.5 秒にする場合:**
  ```powershell
  .\run.bat --page-delay 2.5
  ```

### 一時画像(PNG)を残す (`--screenshots`)
デフォルトでは PDF 生成完了後に一時的なスクリーンショットフォルダ(PNG画像群)は削除されます。PNGファイルもそのまま残したい場合は `keep` を指定します。
- **PNG画像を削除せず残す場合:**
  ```powershell
  .\run.bat --screenshots keep
  ```

## 5. よくあるトラブルと対処法 (トラブルシューティング)

#### 1. ページめくりが実行されず、1ページ目だけで終了してしまう
- **対処法A (フォーカス不足):** `.\run.bat` を実行して Enter を押す直前に、Kindle の書籍本文表示エリアを必ずマウスでクリックしてください。
- **対処法B (キー設定の不一致):** 本によってめくりキーが異なる場合があります。`.\run.bat --direction space` でスペースキーめくりもお試しください。
- **対処法C (管理者権限の競合):** PowerShell や コマンドプロンプトを「管理者として実行」している場合、Windows のセキュリティ仕様 (UAC) により、一般ユーザー権限で起動している Kindle にキー入力を送信できません。ターミナルは管理者として実行せず、**一般ユーザー権限で起動** してください。

#### 2. 画像がズレている / 画面の左上しか写らない
- **対処法:** ディスプレイ設定の拡大縮小設定が **100%** になっているか再確認してください (125% や 150% では正しくキャプチャできません)。設定変更後は Kindle アプリを再起動してください。また、Kindle をサブモニターで表示している場合もズレが発生することがあります。メインモニターに Kindle ウィンドウを移動させてください。

#### 3. 「`uv` コマンドが見つからない」または「`where` は内部コマンド...」のようなエラーが出る
- **対処法:** `uv` をインストールした後に、PowerShell ウィンドウを開き直していない可能性があります。開いているすべてのターミナルを閉じ、新しく起動し直して実行してください。また、PC 自体を再起動すると確実に反映されます。
